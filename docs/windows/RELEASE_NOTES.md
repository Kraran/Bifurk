Bifurk — Chroniques d’aventure, interface Le Grimoire.

Distribution portable pour Windows 10/11 x64 : télécharger le ZIP, l’extraire
entièrement dans un dossier personnel puis lancer `Bifurk.exe`. Python n’est pas
nécessaire. Le dossier `_internal` doit rester à côté de l’exécutable.

Le lecteur doit importer son propre livre PDF. Aucun livre ni aucune sauvegarde
personnelle n’est inclus. Les données sont créées dans `donnees` au premier lancement.

Pour mettre à jour, fermer le jeu et sauvegarder le dossier `donnees` avant de le
recopier dans le dossier de la nouvelle version. Seules les sauvegardes au format
actuel sont acceptées.

L’archive est accompagnée de son empreinte SHA-256 et des informations sur les
composants tiers. L’exécutable n’est pas signé numériquement.
